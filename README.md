# UniTasks

### What is UniTasks?
UniTasks is a bundle of GitHub repositories that together make an archive of all the projects I wrote for university assignments. Right now you're seeing index repo. From here you can access other modules UniTasks includes.

### Why does it exist?
UniTasks's only goal is to bring all the projects together and create a modular system of repositories all of which can be managed independently. This way it is easy for you to find all those projects and it is easy for me to add new ones.
