# UniTasks

### What is UniTasks?
UniTasks is a bundle of GitHub repositories together making a modular archive of all the projects I wrote for university assignments. Right now you're seeing it's index repo. From here you can access other modules UniTasks includes.

### Why does it exist?
UniTasks's only goal is to bring all the projects together to make a modular system of repositories all of which can be managed independently. This way it is as easy for you to find all projects made at specific periods of time as it is easy for me to add new ones.
